# Оно тебе надо

Главная страница аукциона вещей, в которые никто не верил. Проектная работа по HTML и CSS для второго спринта Яндекс Практикума.

## Открыть проект

Откройте `index.html` в браузере. Для просмотра не нужны сборка, пакеты или локальный сервер.

## Реализация

- Семантическая структура: шапка, обложка, список лотов, описание аукциона и подвал.
- Раскладка через Grid и Flexbox, общий затемняющий слой для обложки и карточек.
- Локальные шрифты и изображения из официальной заготовки.
